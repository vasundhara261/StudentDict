# Student Information Dictionary

## Project Overview
The Student Information Dictionary is a beginner-friendly Python project that stores and manages student records using Python dictionaries.

This project was developed as part of Task 7 of my AI & ML internship at VEDA Technology.

## Objectives
- Understand Python dictionaries and key-value pairs.
- Store student information in a structured format.
- Search for student records using unique student IDs.
- Add new student records.
- Update existing student information.
- Display all student records.

## Technologies Used
- Python
- Jupyter Notebook

## Features
1. **Search Student:** Find a student's details using their ID.
2. **Add Student:** Add a new student record.
3. **Update Student:** Modify existing student information.
4. **Display Students:** View all stored student records.

## Student Information
Each student record contains:
- Student ID
- Name
- Age
- Course
- Marks

## How to Run
1. Download or clone this repository.
2. Open `Student_Information_Dictionary.ipynb` in Jupyter Notebook or Google Colab.
3. Run the notebook cells in order.
4. Test the search, add, update, and display functions.
